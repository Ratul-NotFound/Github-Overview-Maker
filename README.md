## 🐍 1-Click Automated Snake Contribution Graph

Want an animated snake eating your contribution grid like this?

<div align="center">
  <img src="https://raw.githubusercontent.com/Platane/snk/output/github-contribution-grid-snake.svg" alt="Snake preview" width="80%" />
</div>

1. Copy [.github/workflows/snake-game.yml](.github/workflows/snake-game.yml) into your profile repository at `.github/workflows/snake-game.yml`.
2. In your profile repository settings, navigate to **Actions > General > Workflow permissions** and select **"Read and write permissions"**.
3. Add the snake markdown snippet from [04-live-widgets-and-actions.md](components/04-live-widgets-and-actions.md) to your `README.md`.
